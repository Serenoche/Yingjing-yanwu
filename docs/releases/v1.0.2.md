# 影境演武 v1.0.2（预发布）

这是首个 GitHub 成品预发布包，面向拥有兼容版本《影之刃零》的 Windows 玩家。下载 **`yingjing-yanwu-v1.0.2-windows-x64.zip`**；GitHub 自动生成的 **Source code** 压缩包只有源码，不能当作 MOD 安装包使用。

## 功能

- 从游戏主菜单进入「影境演武」，支持测试场、练习模式与挑战模式。
- 对决「一决高下」、连战「血战到底」、群战「一夫当关」。当前配置开放 85 项挑战：65 对决、14 连战、6 群战。
- 可选故屋幻景·夜、湖畔；设置轮回、技能、敌人难度，使用游戏内铃铛调整能力和目标。
- 练习模式提供 AI、自动回血、无敌、无限大招、无限暗源开关。
- 支持演武配装记忆、战后结算与历史战报。普通游戏与演武使用各自的保存上下文。

## 本版调整

## 支持版本与前置

- Steam Windows x64，游戏版本 **CL-302256_JKS-17280**。
- 对应 `platform/steam/PBZ.exe` SHA-256：
  `4415933ce33476f14c837abb61a1b60af8b78cd81783896501913a7aac69e423`。
- 已内置匹配的 PBZ 定制 UE4SS、UEHelpers 和保存保护组件，无需另外安装 UE4SS 或 PBZModLoader。
- UE4SS 需要 **Microsoft Visual C++ v14 x64 运行库**，缺少时使用[微软官方下载](https://aka.ms/vc14/vc_redist.x64.exe)。
- 安装器使用 .NET Framework 4.x 与 Windows PowerShell 5.1，Windows 10/11 通常已提供。玩家不需要 Python、Node.js、虚幻编辑器或外部 Oodle。

## 安装与升级

1. 先正常进入游戏并创建至少一次自动或手动存档，然后退出游戏。
2. 完整解压成品 ZIP，保留整个目录；运行其中的 **「影境演武安装器.exe」**。
3. 选择 `platform/steam/PBZ.exe` 和自己的存档账号，点击「安装 / 更新」。已有 1.0.0 或 1.0.1 可直接更新，不必先卸载。
4. 安装成功后从 Steam 正常启动游戏，在标题菜单选择「影境演武」。

安装器先备份并校验原有存档，再加入 18 个 MOD 专用预设。安装失败时会按已验证的事务状态回滚；遇到不支持的游戏版本、其他加载器或未知文件会停止操作。

## 卸载与数据

退出游戏后运行同一个安装器，选择卸载。卸载移除本包管理的运行文件，保留普通进度、演武预设、挑战记录、配装记忆和备份，不会用旧备份覆盖后续进度。

演武资料位于 `<游戏>/ProjectPBZ/Saved/PBZTestArena/<所选账号>/`。发行包没有打包作者的个人正式存档、账号配置、挑战记录或配装记录。

## 预发布边界

- 本包已通过文件完整性、离线逻辑、保存保护和安装交易检查；开发过程中部分实机流程由玩家验证，仍待更多账号与机器测试。
- 首次安装后建议验证：普通继续游戏 → 返回标题 → 进入演武 → 退出演武 → 普通档在铃铛保存。
- 游戏内 Lua 对中文或其他非 ASCII 游戏目录的完整兼容性尚未确认，建议使用英文游戏目录；安装包本身可放中文目录。
- 当前成品不支持小黑盒等管理器直接导入，也不承诺与其他 UE4SS MOD 混合安装。请使用随包安装器。
