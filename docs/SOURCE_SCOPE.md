# 源码范围与排除项

## 包含

- `src/runtime/Scripts`：手写 Lua 逻辑；本项目自定义配置生成的目录/场景 Lua；纯路径、尺寸与 UV 的画像元数据。
- `src/save_barrier`：原创、固定游戏版本的保存事务保护及只读 provider 身份校验；`tests` 使用合成内存和明确虚构的账号路径。
- `src/save_tool`：原创 Windows CNG PBZS 容器校验和暂存工具；模板哈希由本地构建输入生成。
- `src/installer`：原创安装交易脚本、路径发现和 WinForms 宿主源码。
- `tools`：可配置的构建入口。它不安装 MOD、不操作游戏。
- `config`：经审查的 MOD 配置与最小互操作标识；它不包含模型、纹理、音频或原始解包数据表。

第三方 JSON 头文件是明确标注的例外，保留原 MIT 许可证与版权信息。UE、UE4SS 及游戏代码和资源不随这些原创源码一起重新授权。

## 不包含

- 游戏可执行文件、任何 DLL/EXE/OBJ/EXP/LIB 等构建产物或第三方 UE4SS 发布二进制。
- 真实或合成的 `.sav`、`.pbzs`、私有槽模板、安装所有权收据、个人配置、Steam 账号、Windows SID、游戏运行日志、旧报告。
- `UiAssets` 的 PNG/JPG、AI 派生人像、游戏解包纹理、视频、音频、模型、原始 dump 或大型表正文。
- 作者工作区、编译器、游戏安装目录的绝对路径；测试中的跨盘路径是明确虚构的 fixture，不用于发现用户文件。
- 已有安装状态、备份、个人配装偏好和启动参数文件。

公开源码树不应从原工作区整目录复制，也不能把本地输入目录或构建目录加入版本控制。发布审核还应逐项检查将提交的文件，而不是仅检查忽略规则。
