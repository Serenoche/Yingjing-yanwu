# 影境演武 2.0.2

## 安装与入口

- 安装前检查解压路径、游戏目录、现有 UE4SS、旧安装和待恢复的文件事务。按当前状态提供覆盖更新、修复或恢复选项。
- 主菜单可在存档索引加载时显示「影境演武」。等待期间点击会提示稍后重试，进入前继续检查普通存档及账号。
- 通过 Windows 目录联接打开游戏时，安装目录和存档按实际文件身份核对。
- 支持的 Steam 参考版在挑战和练习的难度列表中提供「自订」压力。旧版 Steam 和 Epic 兼容流程使用预设难度。

## 浊梦

- 浊梦四图流程在开门时异步准备下一层首批敌人。挑战和练习从结算页或铃铛重试时，提前加载第一阶段的敌人。
- 调整前 10 层普通杂兵强度及各职阶的玩家削气强度。第 41 层起，首领与具名精英在非破防时可回复杀气，回复速度在第 90 层达到上限。
- 退出或闪退后可从上一个存档点继续。死亡按当前存档点规则结算。
- 修复杂兵提前占用攻击名额。101 层风雪刀客可在玩家倒地、被击飞或冰冻时继续追击。浊梦中玩家所受冰冻、麻痹等控制时长缩为原来的三分之一。

## 练习

- 可用 F4 切换右上角练习面板的显示状态。
