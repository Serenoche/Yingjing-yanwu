# 影境演武 · 本地发行包 @VERSION@

本目录包含已在本机组装的安装文件，不是源码仓库。组装过程没有安装
MOD、启动安装界面或启动游戏。需要你退出游戏后，手动运行安装器。

## 安装和卸载

1. 完整解压并保留整个目录。
2. 退出游戏，双击根目录的 **影境演武安装器.exe**。
3. 选择自己的 `platform/steam/PBZ.exe` 和存档账号，点击“安装 / 更新”。
   多个 Steam 库或账号需要明确选择；安装器不会替你随意选一个。
4. 完成后从 Steam 正常启动游戏，在主菜单进入“影境演武”。

卸载时先退出游戏，再打开同一个安装器，点击“卸载（保留进度）”。
也可使用 `IntegratedMenu/` 中的安装、卸载 `.cmd` 入口。
卸载只移除本包管理的运行时，保留存档、挑战记录、配装记忆和备份。
无需另装 Node、Python、虚幻引擎或 Oodle 来运行此安装器。
UE4SS 加载器可能另外需要 Microsoft Visual C++ x64 运行库，请按该组件的要求配置。

安装会先备份当前存档，再加入专用演武预设；普通存档块和“继续游戏”
账户数据按字节保留。首次使用前，需要先正常新游戏并创建至少一次
自动或手动存档，然后退出游戏再安装。检测到游戏运行、未知代理 DLL、
其他 UE4SS/MOD 或不匹配的私有存档内容时，安装器会停止操作。

本机持久数据和备份位于：

```text
<游戏>/ProjectPBZ/Saved/PBZTestArena/<所选Steam账号>/
```

游戏在受保护目录时，点击安装或卸载后可能请求管理员授权。权限调整
只针对本包独占运行时和上述数据目录；正常启动游戏不需要管理员权限。
发行包不会自动收集或附带组装者的普通账号存档、战报或配装资料；
本地提供的私有预设内容仍需组装者另行审核。

## 支持版本与验证边界

支持 `CL-302256_JKS-17280`，游戏文件 SHA-256：

```text
@GAME_SHA256@
```

其他游戏版本会拒绝安装。`PackageManifest.json`、`SHA256SUMS.txt`
和 `BuildProvenance.json` 记录本地文件及输入指纹，不是第三方数字签名。
本地组装与离线检查不代表这一次构建已经通过实机测试。

安装器和存档工具已验证 Windows Unicode 路径，但游戏内 Lua 对中文或
其他非 ASCII **游戏目录**的兼容性尚未确立，建议使用已验证的英文游戏目录。
