# 影境演武 / Yingjing Yanwu 1.1.0

## 中文

- 新增自订挑战，支持最多 5 连战或 5 目标群战。
- 新增目标异常状态条，优化练习开关、首领信息和结算体验。
- 改善配装记忆与药瓶补充，每轮挑战开始时补满当前装备的药瓶，连战阶段间保留消耗。
- 修复荆野骑乘与锁定、白赤练召蛇等问题，改善战斗稳定性。
- 优化已有 UE4SS 环境的安装兼容，加入已测试旧版 Steam 游戏的针对性适配。

验证范围：Steam Windows x64 参考版本 `CL-302256_JKS-17280`，以及 `301524-17219` 与 ModCraft 来源 UE4SS 的玩家测试组合。其他版本、前置组合及 EPIC／WeGame 尚不保证兼容。

## English

- Added custom challenges with up to five consecutive fights or five simultaneous targets.
- Added target status bars and improved practice controls, boss information and results presentation.
- Improved loadout memory and medicine refills. Equipped bottles start full on a new attempt; charges carry over between gauntlet stages.
- Fixed Jingye's mount and targeting, Bai Chilian's summons, and other encounter issues.
- Improved installation alongside existing UE4SS and added targeted support for the tested older Steam build.

Tested coverage: Steam Windows x64 reference build `CL-302256_JKS-17280`, plus the player-tested `301524-17219` / ModCraft UE4SS combination. Compatibility with other builds, loaders, Epic or WeGame is not guaranteed.
