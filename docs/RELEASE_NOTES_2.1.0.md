# 影境演武 2.1.0 更新说明

## 场地与进场

- 原版存点流程扩充至 **52 处场地**，覆盖悲泣溪谷、血色森林、陆家村、庞镇、梅谷湖、戏梦山庄、断魂山、正道大营和枷笼山等地区。包含 13 处通用、27 处 SOLO 通用和 12 处首领专属。测试场与群战使用通用场地，练习和挑战按目标及挑战类型显示可用场地。SOLO 通用与专属场地按预设对决或连战开放。
- 场景页按地区浏览，可预览原版存点画像和场地类别。对决及预设连战可按目标推荐场地。更换模式或目标后，原选择仍合适就保留，失效则回到「默认」。普通游龙默认去庞镇「浅水塘」，发狂游龙默认去「水行帮船坞」。
- 演武进场和地图补载时会清理原场景里的宝箱、追忆花、剧情道具、悬挂掉落物和可掉落物品的容器。各场地按自身规则启用铃铛、雾门和通行机关。

## 连战与首领机制

- 选择「默认」场地时，带有专属路线的预设连战会随阶段换场，并保留玩家血量、资源、药品次数和累计战斗统计。「三位一体」从三面封印地的「三张脸的诡异魔偶」打起，再转血色森林。「灭法之法」分四场，最后一场由寒岁与活人偶清道夫同场。更新「怪面之乱」「坚如磐石」「绝望的背叛」的换场路线，荒行子两阶段分别在「宗祠内殿」和「锯轮幻境」。
- 新连战「七星鸳鸯阵」取代「绝命鸳鸯」。三高塔第一阶段为大师兄与六名白衣剑客，第二阶段为大师兄的绝望剑意与剑阵版红衣女剑客，并接入原版剑傀队伍。陆家村浅滩船坞的阿瑾也恢复与六名红衣剑客同行的原版编队。
- 新增群战「少主护卫：铁鬼与玉妖」。两人的联动招式也接入「少主的决意」第三阶段。「吞噬尸体的小雪」退出原版存点流程的对决及自订候选。
- 补齐通用场地中的首领机制，包含白赤练的召蛇点、舞狮的桩区、左殇的大招落点、雷当二阶段的回落点、独眼弓客的中心与地眼。舞狮两阶段恢复原版的热量、过热及喷火机制，「最后的传承」在两阶段之间延续热量。
- 通用与 SOLO 场地增加防坠和越界回位检查。连战从下一阶段首领入场时开始保护，同图切阶段和跨图切换均适用。首领因地形离场且无法安全回位时，本轮可自动从第一阶段重开，并提示出问题的阶段。

## 菜单、角色与装备

- 测试场、练习和挑战采用分级菜单，「进入战斗」位于总览左侧末项。练习和挑战可按地区选对手，分别设置场景和战斗音乐。主菜单和设置页更新水墨背景，详细设置页增加深色底衬。
- 战斗音乐页采用原版设定集样式，显示曲目信息与试听进度，支持试听、暂停和继续。
- 演武铃铛按场地显示名称，例如「锈刃凉亭」。练习与挑战的「更换目标」打开新版总览，默认选中「目标」，选完回总览按「确认更换」应用，或返回铃铛取消。修复原版存点流程中首次开铃触发同步存档诊断时可能发生的卡顿。
- 原版存点流程的角色设定按「牢」及轮回 0–6 档位保存。可调整属性、收集品及装备并预览结果，可恢复本页或将单项切回「跟随养成」。支持按轮回参考刻度取值，技能增幅位于收集品页，异常累积上限可直接拖动。
- 原版存点场地的铃铛新增「装备调整」，沿用原版武器强化界面。可免费强化武器，等级上限取角色设定与武器自身上限中的较低值。按手柄 **X** 或键盘 **P** 进入铸魂页，在具备铸魂的武器上长按手柄 **A** 或**空格**切换。重载预设会恢复该档位初始武器状态。
- 测试场复用角色设置和场地筛选。「目标」页可按强度、战斗定位和家族筛选杂兵，并设置敌人轮回与难度。场内铃铛的「重选目标」使用同一份杂兵与木桩列表。

## 测试场木桩

- 在目标页或测试场铃铛选择木桩，按 **F8** 生成。木桩固定位置并保持满血，左上角显示最近伤害、累计伤害、命中次数和 DPS。
- 按 **Delete** 清零伤害统计，按 **F10** 清除当前选中的木桩。多个目标可按 **F5** 切换。DPS 以本轮首次至最后一次有效命中的游戏时间计算，计时下限为 1 秒。

## 浊梦与场地修复

- 重排浊梦三面封印地的 **3 个玩家回位点、5 个杂兵点和 3 个首领点**，覆盖五怪楼层与第 101 层第二阶段的双首领。原版存点流程按玩家入场朝向在新点位排出近战前排、远程后排，准备铃显示「浊梦之间」。
- 包含此前的浊梦刷怪修复。原版杀气上限为零的杂兵可正常生成，避免第 2、7 层等楼层出现空场。
- 修正左殇、舞狮尊主、白赤练与冷荼的场景对象匹配，减少原版对象与演武对象冲突导致的刷怪失败。锈刃凉亭右侧楼梯的常驻雾效会恢复，战斗入口雾门在备战时开放，交战后关闭。
