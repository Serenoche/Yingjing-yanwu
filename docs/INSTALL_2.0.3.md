# 影境演武 2.0.3 安装说明

1. 完全退出游戏和 MOD 管理器，等平台同步存档。使用过专项内测的玩家，请先用对应内测包的还原功能。浊梦刷怪短测的还原选项是测试 CMD 中的 **R**。
2. 把 ZIP 完整解压到游戏目录外的短路径，例如 `D:\PBZMod`。打开「影境演武安装器.exe」，选中游戏和正在使用的存档账号，再点「检查安装」。首次游戏没有存档时，请先在本篇保存一次。
3. 按检查结果选择安装、覆盖更新或修复。安装器优先复用已识别的 UE4SS，并保留其他 MOD。选择覆盖选项前，留意安装器列出的替换范围。
4. 安装成功后，从原游戏平台正常启动。在标题页的「读取存档」下方选择「影境演武」。若提示正在读取存档，稍等几秒再进入。

## 常见情况

- **提示解压路径过长或文件不全**。把完整 ZIP 重新解压到短路径后再打开安装器。
- **提示游戏目录字符不兼容**。请通过 Steam 或 Epic 把游戏移到纯英文路径的游戏库，再选新位置检查。
- **更新时检测到旧安装**。选回原游戏位置和原存档账号。安装器会先备份，再覆盖可识别的旧演武。若有无法确认归属的同名 MOD，请在原管理器中处理，或先把它备份并移出 Mods 目录，再重新检查。
- **主界面没有入口**。检查是否启动了安装时选中的那份游戏，确认「PBZTestArena」在现有 MOD 管理器中已启用，然后完全重启游戏。仍无入口时，打开安装器复查并点「导出诊断」。
- **挑战或练习的难度列表没有「自订」**。自订压力需要受支持的 Steam 参考版游戏和能加载压力组件的 UE4SS。旧版 Steam 和 Epic 兼容流程使用预设难度。若在 Steam 参考版仍无「自订」，用安装器检查 UE4SS 并导出诊断。
- **安装中断**。重新打开安装器。若出现「恢复上次操作」，先恢复再重新检查。若恢复仍失败，请保留备份并导出诊断。

通过安装器导出的诊断包不包含存档。卸载时使用安装器的「卸载」，保留本篇存档和独立的演武进度。
